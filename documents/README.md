# NBO free observation program: documents

Program: free NBO practice observation visits by an NBO trainee of ConnectEd Kids Therapy Center, for families of babies from birth to about 3 months, alongside the parenting class.

- `Word/` editable files (.docx), by group. `PDF/` print-ready copies (same names).
- Start with `Word/00_Document_Index.docx` (contents, translation map, fill-in items, order of use).
- Each `_Taglish` file is a translation of the `_EN` file with the same number and name. Its source file is named in a line under its title.
- Items highlighted yellow in the Word files are fill-ins (your name, credentials, mentor, class details, visit location, visit length, retention period, Data Privacy Officer).
- The official NBO Recording Form, Recording Guidelines, Parent Summary, Narrative Form, Certification Guide, Fidelity Checklist, and AMOR reference card are not reproduced here. Use the originals.
