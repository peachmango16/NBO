# NBO free observation program: documents

Program: free one-to-one NBO observation visits with a licensed practitioner in NBO training, at ConnectEd Kids Therapy Center, for families of babies from birth to about 3 months. It is an observation visit, not a class.

- `Word/` editable files (.docx), by group. `PDF/` print-ready copies (same names).
- Start with `Word/00_Document_Index.docx` (contents, translation map, fill-in items, order of use).
- **Parents sign the English consent forms.** Each `_Taglish` file is a reading aid for the `_EN` file with the same number and name (the source is named under its title). There is no official Filipino or Taglish translation of the NBO.
- No practitioner name appears on any family or public document; they say "a licensed practitioner."
- Items highlighted yellow in the Word files are fill-ins (visit location, visit length, retention period, secure storage, dates and times).
- The official NBO Recording Form, Recording Guidelines, Parent Summary, Narrative Form, Certification Guide, Fidelity Checklist, and AMOR reference card are not reproduced here. Use the originals.
